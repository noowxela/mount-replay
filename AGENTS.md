# AGENTS.md: mount-replay

Vite + TypeScript + Three.js, no framework. Data in `public/data/` is generated by `scripts/bake.py` (Python, numpy, tifffile; needs the two Copernicus GLO-30 tiles and an Overpass JSON); do not hand-edit it.

Rules
- Never invent numbers. Heights, distances and times come from the cited sources in README; anything else is labelled "typical" or "estimate" in all three languages.
- Keep `src/i18n.ts` EN / zh / ms in sync (`npm run i18n` fails otherwise).
- Media stays client-side: no network requests with user files, no analytics.
- Before committing: `npm run typecheck && npm run i18n && npm run build`, then the smoke check with no console errors.
- Respect `prefers-reduced-motion` (no autoplay, no sweep, instant camera moves).
